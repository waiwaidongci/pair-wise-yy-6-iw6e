运行：

```bash

```

访问 `http://localhost:3037`。

- 墨锭试磨室：`/`，数据保存在 `data/ink-stick-testing.json`
- 借样登记台：`/loan`，数据保存在 `data/loan-archive.json`

## 借样登记台

成品墨锭外借做书写样张时在此登记，规则、档案、页面三者分离：

| 文件 | 职责 |
| --- | --- |
| `loan-rules.js` | 借样规则（纯逻辑，可单测） |
| `data/loan-archive.json` | 借样档案：库管名册与借样单 |
| `public/loan.html` | 登记台页面 |

规则要点：

- 每锭墨锭同时只允许一张「未归还」单；重复申请沿用首次单据，不新建。
- 缺留样编号、保管人离岗、温度越界（15~25℃）或湿度越界（45%~65%）时**整单退回**，一次性给出全部原因，档案不写半截数据。
- 归还由**另一位库管**核验重量与边角：较出库少 0.5 克及以上，或边角有裂角，单据转「待鉴定」；否则转「已归还」。
- 修改墨锭编号或保管人，该锭未结（未归还）单据立即失效并入只读档案，旧记录保留旧编号快照、不可再改。
- 列表可按「未归还 / 待鉴定 / 已归还」三种状态筛选，失效单据单列只读区。
